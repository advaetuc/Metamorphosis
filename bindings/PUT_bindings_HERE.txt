MetaMorphosis reads .dna files through the OpenRigLogic Python bindings (MIT, Epic Games).
They are native binaries, so they cannot be generated by this add-on.

Copy the contents of the 'bindings' folder of Poly Hammer's Character DNA add-on into THIS folder,
so that this folder contains dna.py, riglogic.py and the compiled _py3dna*/_py3riglogic* files
for your platform. Alternatively keep that add-on enabled while importing (it is detected
automatically), or set the folder in Edit > Preferences > Add-ons > MetaMorphosis.

Only importing needs the bindings. The imported rig is plain Blender drivers.
