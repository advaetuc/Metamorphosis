MetaMorphosis reads .dna files through the OpenRigLogic Python bindings (MIT, Epic Games).
They are native binaries, so they cannot be generated by this add-on.

Copy Poly Hammer's whole 'bindings' folder into THIS folder (sub-folders are fine). MetaMorphosis searches
below this folder for dna.py, riglogic.py and the compiled _py3dna*.pyd / _py3riglogic*.pyd files.

Or leave them anywhere and set the folder in Edit > Preferences > Add-ons > MetaMorphosis, then press
"Test Bindings". Keeping Poly Hammer's add-on enabled also works.

Only importing / rebuilding needs the bindings. The imported rig is plain Blender drivers.
